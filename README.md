# Qoutes

**Live Demo:** [task-ebon-ten.vercel.app](https://task-ebon-ten.vercel.app/)

---

## 📖 About the Project  
Qoutes is a front-end web application built using **HTML** and **JavaScript** (no framework) to provide a simple task management interface. It demonstrates core front-end skills: HTML structure, JS logic, DOM interaction, and clean UI.

---

## 🧰 Technologies Used  
- **HTML5** – for semantic markup and structure  
- **JavaScript (ES6+)** – for dynamic behavior and DOM manipulation  
- **Bootstrap** – for styling, layout, and responsive considerations  
- **Responsive Design** – ensures usability across devices (desktop, tablet, mobile)  

---

## 🎨 Key Features  
- Create, view, and maybe delete tasks (depending on functionality) via JavaScript  
- Clean and intuitive UI built purely with HTML/JS (minimal overhead)  
- Easily deployable as a static front-end project  
- Great portfolio project to showcase core front-end competency
